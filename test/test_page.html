Solving the Quadratic Equation

For the equation $ax^2 + bx + c = 0$ (with $a \ne 0$), the discriminant is defined as:

$$\Delta = b^2 - 4ac$$

When $\Delta > 0$ there are two distinct real roots, given by the quadratic formula:

$$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

Discriminant vs. roots

DiscriminantRootsExample
$\Delta > 0$two distinct real roots$x^2 - 3x + 2 = 0$
$\Delta = 0$one repeated root$x^2 - 2x + 1 = 0$
$\Delta < 0$a pair of complex conjugate roots$x^2 + 1 = 0$

Python solution

import cmath

def solve(a, b, c):
    """Solve ax^2 + bx + c = 0"""
    delta = b*b - 4*a*c
    x1 = (-b + cmath.sqrt(delta)) / (2*a)
    x2 = (-b - cmath.sqrt(delta)) / (2*a)
    return x1, x2

print(solve(1, -3, 2))  # (2+0j), (1+0j)

Note: when $a = 0$ the equation degenerates to a linear one and must be handled separately.

See the Wikipedia article for more. Inline code example: delta = b**2 - 4*a*c.
